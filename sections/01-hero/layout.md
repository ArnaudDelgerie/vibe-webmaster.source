# Layout — Accueil

## Structure
Le bandeau d'accueil (hero) : une seule phrase d'accroche — « Créer gratuitement un site comme ce site, grâce à ce site ». Aucun autre élément.

## Affichage
Fond sombre (bandeau pleine largeur) avec un halo orange subtil derrière l'accroche, qui s'éteint vers le noir sur les bords — effet « outil tech » moderne, aucune image. Texte centré, typographie grande et nette. C'est le tout premier écran vu par le visiteur, avant même le menu : la phrase doit se lire en une seconde.
