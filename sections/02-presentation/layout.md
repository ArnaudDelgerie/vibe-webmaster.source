# Layout — Présentation

## Structure
Une accroche d'un paragraphe (ce que fait cette page), puis quatre blocs successifs : « Un site statique, c'est quoi ? » (définition, qualités, limites honnêtes, rôle de l'agent Webmaster), « GitHub, une plateforme d'hébergement de dossiers versionnés » (les 2 repositories : source et site), « GitHub Pages, un hébergement gratuit avec ses limites » (1 Go, 100 Go/mois, exemple concret, noms de domaine), et « Adapté à votre IA préférée » (court paragraphe de clôture).

## Affichage
Texte sur une seule colonne, lecture continue vers le bas, titres de niveau 2 pour les blocs. Aucune image nécessaire ; les chiffres (1 Go, 100 Go, 20 000 vues) peuvent être mis en valeur discrètement.
