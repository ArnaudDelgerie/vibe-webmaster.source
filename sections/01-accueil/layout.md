# Layout — Accueil

## Structure
Une accroche d'un paragraphe (la promesse du guide), puis trois blocs : « Ce que vous obtenez au final » (liste), « Avec quels outils » (liste : Vibe, GitHub Pages), et « Le coût réel : 0 € » (paragraphe + phrase de clôture sans formulaire ni inscription).

## Affichage
Texte sur une seule colonne, lecture continue vers le bas, titres de niveau 2 pour les blocs. La rubrique suit directement le bandeau d'accroche du thème (hero) qui porte la promesse en une phrase — pas de répétition entre les deux.

## Particularités
Première rubrique de la page, juste sous le bandeau d'accroche. Des ancres de menu ou boutons renvoient vers les rubriques suivantes (« Le concept », « Le guide étape par étape »). Les noms d'outils (Vibe, GitHub) en gras.
