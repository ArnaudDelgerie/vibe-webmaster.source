# Layout — Le concept

## Structure
Une accroche d'un paragraphe, puis trois blocs successifs : « Un site statique, c'est quoi ? » (les deux familles de sites en comparaison, puis les limites honnêtes en liste), « Comment Vibe WebMaster fait disparaître ces limites » (liste), et « GitHub Pages : un hébergement gratuit, avec ses règles » (paragraphe avec l'exemple de bande passante).

## Affichage
Texte sur une seule colonne, lecture continue vers le bas, titres de niveau 2 pour les trois blocs. Les listes bénéficient d'un interligne généreux pour rester lisibles chez un public non initié. Aucune image nécessaire.

## Particularités
Ancre de menu « Le concept ». Les chiffres (1 Go, 100 Go, dizaines de milliers de pages vues) en gras pour être repérables d'un coup d'œil. Ton pédagogique conservé : analogies de la brochure imprimée et du classeur bien rangé.
