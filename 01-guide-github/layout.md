# Layout — Guide GitHub

## Structure
Une accroche d'un paragraphe (le parcours GitHub : compte, deux dossiers, mise en ligne). Les étapes détaillées du guide vivront dans les blocs de cette page, ajoutés progressivement.

## Affichage
Texte sur une seule colonne, lecture continue vers le bas. Les futures étapes s'afficheront comme des blocs successifs avec titres de niveau 2.
